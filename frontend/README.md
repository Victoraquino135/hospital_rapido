# Flutter UBS Rápida

Interface existente para Windows, Web e Android, preservando logo, cores, ondas, cartões e dashboards. Dados compartilhados exclusivamente pela API.

Configure o endereço com `--dart-define=API_BASE_URL=...`. Instruções completas em [ATUALIZACAO_INTEGRACAO.md](../docs/documentacao_projeto/ATUALIZACAO_INTEGRACAO.md).
