# Flutter UBS Rápida

Interface existente para Windows, Web e Android, preservando logo, cores, ondas, cartões e dashboards. Dados compartilhados exclusivamente pela API.

Configure o endereço com `--dart-define=API_BASE_URL=...`. As instruções originais de integração foram preservadas no [arquivo histórico](../docs/99_arquivo_historico/acervo_documentacao_projeto/ATUALIZACAO_INTEGRACAO.md).
