# Arquivo histórico

Esta pasta guarda materiais substituídos ou de apoio que podem ter valor acadêmico, mas não são referência operacional do sistema.

- `acervo_documentacao_projeto/`: relatórios antigos, referências, imagens, PDF e cópia histórica de código;
- `planos_de_desenvolvimento/`: planos e especificações usados durante etapas anteriores.

Os arquivos daqui não são importados nem executados pela aplicação. Não use conteúdo histórico como instrução de instalação sem conferir os READMEs atuais.
