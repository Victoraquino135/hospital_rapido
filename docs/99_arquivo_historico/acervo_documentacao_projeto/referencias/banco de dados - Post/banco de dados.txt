Banco de Dados — PostgreSQL

O sistema utilizará o PostgreSQL como banco de dados principal da UBS. Ele será responsável pelo armazenamento estruturado e seguro das informações do sistema.

O banco deverá armazenar informações relacionadas a:

Usuários e perfis;
Pacientes;
Responsáveis;
Profissionais;
Especialidades;
Consultas;
Agendamentos;
Fila de atendimento;
Triagem;
Atendimentos;
Encaminhamentos;
Notificações;
UBS;
Salas;
Histórico de operações.

O acesso ao banco será realizado exclusivamente pelo Back-end, evitando que o aplicativo tenha acesso direto ao banco de dados.
